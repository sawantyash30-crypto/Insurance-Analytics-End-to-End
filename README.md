# Insurance-Analytics-End-to-End
End-to-end Insurance Analytics project using Excel, SQL, Power BI, and Tableau to track New, Renewal, and Cross-Sell performance with interactive dashboards and KPIs.
- Renewal business contributes the highest premium, indicating strong retention.
- Cross-sell policies generate higher average invoice value.
- Invoiced achievement lags placed achievement in multiple branches.
- Open opportunities dominate the funnel, reducing conversion ratios.
- High-performing executives have higher meeting counts and win ratios.
